# Plan 03-01: Authentication & Security Hardening

## Objective
Harden authentication and authorization across the entire backend: eliminate backdoor credentials (`Aicte@2026`), secure JWT validation, protect all endpoints with authentication and role-based scope checks, restrict CORS, and eliminate unauthenticated static access to evidence files.

## Tasks
1. **Authentication (`SEC-01`, `SEC-02`, `SEC-03`):**
   - In `backend/src/routes/auth.ts`: Remove backdoor `password !== "Aicte@2026"` check. Ensure bcrypt verification is strictly enforced.
   - In `backend/src/routes/auth.ts`: Remove password from `/demo-accounts` response, and gate endpoint so it returns empty array or 403 when `NODE_ENV === "production"`.
   - In `backend/src/middleware/auth.ts`: Validate `JWT_SECRET`. Fail fast in production if `JWT_SECRET` is missing or is the default sample string.
2. **Authorization & Route Protection (`SEC-04`, `SEC-05`):**
   - Protect `GET /api/complaints` and `GET /api/complaints/:id` with `requireAuth` and institutional/bureau scope filtering.
   - Protect `GET /api/institutions` and `GET /api/institutions/:id` with `requireAuth`.
   - Protect `GET /api/overlaps` and `GET /api/overlaps/:id` with `requireAuth` and bureau/admin role check.
   - Protect `GET /api/transfers` with `requireAuth`.
   - Protect `GET /api/analytics/*` with `requireAuth` and role scoping.
3. **CORS & Static Evidence Protection (`SEC-06`, `VULN-05`):**
   - In `backend/src/server.ts`: Replace wildcard CORS `origin: "*"` with environment-configurable trusted origins list.
   - In `backend/src/server.ts`: Remove `app.use("/uploads", express.static(UPLOADS_DIR))`.
   - In `backend/src/routes/complaints.ts`: Provide an authenticated document download route `GET /api/complaints/:id/documents/:docId/download` with file existence and permission validation.

## Verification
- Attempt login with invalid password and verify 401.
- Attempt login with `Aicte@2026` against user with different password and verify 401.
- Query unauthenticated routes (`/api/complaints`, `/api/institutions`, `/api/analytics/dashboard`) and verify 401.
- Verify CORS blocks disallowed origins.
- Verify uploads are inaccessible without valid token.
